# RJM-Agent: AI-Based Resume Job Matching System

## Overview
RJM-Agent is an AI-powered Resume Job Matching platform that automates resume analysis and job recommendation using NLP and Machine Learning techniques. The system extracts skills and important information from resumes, compares them with job descriptions, and provides accurate matching scores and recommendations.

---

## Features

- Resume Parsing and Information Extraction
- Skill Extraction using NLP
- Job Description Analysis
- BERT-based Semantic Similarity Matching
- Cosine Similarity Score Computation
- AI-Based Job Recommendation
- Resume Ranking System
- User-Friendly Interface
- Fast and Accurate Matching Process
